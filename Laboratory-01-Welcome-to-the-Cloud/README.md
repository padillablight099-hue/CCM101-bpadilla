# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory activity introduces the basic concepts and practical use of a Linux cloud environment. The activity was completed using the KillerCoda Playground.

## Objectives

- Access a cloud-based Linux environment.
- Explore and navigate Linux.
- Gather basic system information.
- Organize files and directories.
- Create and maintain a GitHub repository.
- Document technical work using Markdown.

## Activities Performed

- Accessed the Ubuntu Linux environment using KillerCoda.
- Created a new Linux user.
- Checked the username, working directory, and hostname.
- Gathered system information.
- Created directories and Markdown files.
- Created a Cloud Computing portfolio on GitHub.

## Linux Commands Used

- `whoami`
- `pwd`
- `hostname`
- `cat`
- `uname`
- `lscpu`
- `free`
- `df`
- `cd`
- `mkdir`
- `ls`
- `nano`

## Skills Learned

I learned how to navigate a Linux environment, use basic Linux commands, organize files and folders, create Markdown documentation, and manage a GitHub repository.
