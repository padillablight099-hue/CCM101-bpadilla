## Analysis Questions

### 1. Which cloud provider offers the broadest range of services?
Amazon Web Services (AWS) offers the broadest range of services with over 200 fully featured products across every category, from basic compute and storage to advanced analytics, AI, and enterprise tools. Its ecosystem is deeper and more mature than competitors, with the largest marketplace and longest track record.

### 2. Which provider best integrates with Microsoft technologies?
Microsoft Azure is purpose-built to integrate natively with Windows Server, Microsoft 365, Active Directory, and .NET applications. Organizations already using Microsoft products can migrate workloads with minimal changes, unified identity management, and consistent licensing across on-premises and cloud environments.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?
Google Cloud Platform (GCP) leads in both areas — Google invented Kubernetes and offers Google Kubernetes Engine (GKE) as the most mature and feature-rich managed container service. GCP also provides industry-leading AI tools including Vertex AI, purpose-built TPUs, and seamless integration with Gemini and TensorFlow.

### 4. Which cloud platform would you personally choose and why?
I would personally choose Google Cloud Platform for its clean interface, transparent pricing, and technical leadership in AI and containers. Its high-performance global network and modern approach make it ideal for cloud-native development and future-ready applications, while still offering all the core services needed for general workloads.
