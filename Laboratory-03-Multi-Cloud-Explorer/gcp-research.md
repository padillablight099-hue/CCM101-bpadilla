# Google Cloud Platform (GCP) Research

## Brief Overview
Google Cloud Platform (GCP), launched in **2008**, is a suite of modular cloud computing services built on the same infrastructure Google uses internally for products like Google Search, Gmail, and YouTube. GCP offers computing, storage, networking, data analytics, and AI/ML — with AI-optimized infrastructure engineered for the age of inference. New users receive **$300 in free credit**, and GCP is widely recognized for leadership in artificial intelligence, Kubernetes, and high-performance global networking.

## Global Infrastructure
GCP operates across **43 geographic regions** and **130 zones**, available in **200+ countries and territories** across six continents. Backed by **10 million kilometers of terrestrial and subsea fiber**, Google's private global network delivers exceptional speed, low latency, and built-in resilience. Each region consists of three or more zones housed in physically separate data centers to ensure high availability and fault tolerance.

## Cloud Management Console
The public website at **cloud.google.com** serves as the entry point, organized with top navigation including Overview, Solutions, Products, Pricing, and Resources. Users can access the management interface directly at **console.cloud.google.com**, sign up for free credit, or browse product documentation and service catalogs.

## Four Core Services
1. **Compute Engine** — High-performance virtual machines running in Google's data centers. Choose from predefined or custom machine types for web servers, databases, and applications. Offers industry-leading reliability with **99.95% availability SLA** and live migration during hardware maintenance.
2. **Cloud Storage** — Secure, durable, and cost-effective object storage for any data type. Provides multiple access tiers and runs on Google Cloud's proven infrastructure, ideal for backups, archives, big data, and general-purpose file storage.
3. **Virtual Private Cloud (VPC)** — Isolated private network space to control IP addressing, subnets, firewall rules, and global connectivity. Supports a **single VPC for an entire organization**, logically isolated within projects for security and simplicity.
4. **Cloud SQL** — Fully managed relational database service supporting **MySQL, PostgreSQL, and SQL Server**. Automates backups, patching, scaling, and maintenance so you can focus on applications rather than database administration.

## Three Advantages
1. **AI & Kubernetes Leadership** — Google invented Kubernetes and created TensorFlow; Google Kubernetes Engine (GKE) remains the most mature managed container offering. Vertex AI, Gemini, and purpose-built AI infrastructure set GCP apart in machine learning and modern application development.
2. **High-Performance Global Network** — Backed by 10 million kilometers of private fiber connecting 200+ countries, delivering low latency, high throughput, and built-in resilience that few providers can match.
3. **Transparent Pricing & Reliability** — Generous free credit, automatic sustained-use discounts, and **Spot VMs available at up to 91% off** make GCP cost-effective. Also offers the industry's best single-instance availability SLA of 99.95%.

## Typical Enterprise Use Cases
- **AI & Machine Learning Development** — Build, train, and deploy models using Vertex AI, Gemini, and purpose-built AI infrastructure.
- **Cloud-Native & Container Applications** — Deploy microservices on Google Kubernetes Engine (GKE) with consistent hybrid and multi-cloud capabilities.
- **Global Web & Scalable Apps** — Deploy across 43 regions with auto-scaling, live migration, and low-latency global delivery.
- **Managed Databases & Analytics** — Run fully managed SQL and NoSQL databases alongside big data and analytics pipelines.
