# Laboratory 03 – Multi-Cloud Explorer

## Linux Server Investigation

### System Information
This information was gathered from the KillerCoda Linux terminal using the following commands:

- Operating System: Ubuntu
- CPU: 2 Cores
- Memory: 2GB
- Disk Space: 20GB

### Cloud Equivalent Services
If this Linux server were migrated to the cloud, it could be hosted on:

- AWS: Amazon EC2 (Linux instance type)
- Azure: Azure Virtual Machines (Linux VM)
- Google Cloud Platform: Compute Engine (Linux instance)

All three providers offer Linux virtual machines with similar specifications — 2 vCPUs, 2GB memory, and 20GB storage — demonstrating how on-premises servers map directly to cloud resources.
